# DANH MỤC CÁC KÝ HIỆU, CÁC CHỮ VIẾT TẮT

| Viết tắt | Tiếng Anh | Tiếng Việt |
|----------|-----------|------------|
| USB | Universal Serial Bus | Chuẩn giao tiếp nối tiếp đa năng |
| HID | Human Interface Device | Thiết bị giao diện người dùng |
| BadUSB | Bad Universal Serial Bus | Tấn công USB giả mạo |
| KDS | Keystroke Dynamics Security | Bảo mật bằng động học gõ phím |
| CV | Coefficient of Variation | Hệ số biến thiên |
| IQR | Interquartile Range | Khoảng tứ phân vị |
| FT | Flight Time | Thời gian bay (giữa 2 phím) |
| HT | Hold Time / Dwell Time | Thời gian nhấn giữ phím |
| DD | Down-Down | Thời gian down-down giữa 2 phím |
| IF | Isolation Forest | Rừng cô lập (thuật toán ML) |
| OCSVM | One-Class SVM | Máy vector hỗ trợ một lớp |
| RF | Random Forest | Rừng ngẫu nhiên (thuật toán ML) |
| ML | Machine Learning | Học máy |
| AUC | Area Under Curve | Diện tích dưới đường cong |
| ROC | Receiver Operating Characteristic | Đường cong ROC |
| FP | False Positive | Dương tính giả (báo nhầm) |
| FN | False Negative | Âm tính giả (bỏ sót) |
| EDR | Endpoint Detection and Response | Giám sát và phản ứng điểm cuối |
| MITRE ATT&CK | — | Framework phân loại kỹ thuật tấn công |
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| CSV | Comma-Separated Values | File dữ liệu phân cách bằng dấu phẩy |
| CLI | Command Line Interface | Giao diện dòng lệnh |
